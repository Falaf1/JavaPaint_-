JavaPaint — комплект для защиты проекта

Запуск: откройте папку JavaPaint и запустите JavaPaint.exe.
Для переноса на другой Windows x64 компьютер можно использовать архив JavaPaint_Windows_x64.zip. Распакуйте его полностью и запускайте JavaPaint.exe внутри папки JavaPaint.
Среда выполнения Java включена в app-image. Исходники проекта находятся в папке Desktop\paja.
Документы: Техническое_задание_JavaPaint.docx, Описание_программы_JavaPaint.docx, Презентация_защита_JavaPaint.pptx.

Сборка выполнена jpackage из JDK 27. Исполняемая среда Oracle JDK 27 распространяется на условиях NFTC. Сведения о лицензии JDK опубликованы на сайте Oracle.
